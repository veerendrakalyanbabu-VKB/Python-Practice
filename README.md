# Python Practice

A small archive of Python exercises created while building fluency with core language features and command-line program structure.

> This is a learning repository, not a production application. Current product and applied-AI work is documented in the [main engineering portfolio](https://github.com/veerendrakalyanbabu-VKB).

## Exercises

| Exercise | Focus |
|---|---|
| Simple calculator | Input handling, arithmetic, and control flow |
| Number guessing game | Loops, conditions, and random values |
| Student manager | Collections and basic record operations |
| Customer manager | Structured data and command-line workflows |
| Email generators | String formatting and small automation scripts |

## Run an exercise

Use Python 3 from the repository root. Quote filenames that contain spaces:

```bash
python "Simple Calculator.py"
python "Number Guess Game.py"
```

These files preserve the original learning progression, including their historical filenames. New production work follows conventional package structure, automated testing, and CI in the flagship repositories.
